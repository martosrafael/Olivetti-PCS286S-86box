# Dumps originales

Pon aqui los dos chips originales para trabajar en local.

No subas estos ficheros a GitHub. El `.gitignore` de este proyecto excluye esta carpeta salvo este README.

Nombres sugeridos:

```text
chip-uXX.bin
chip-uYY.bin
```

Si las etiquetas fisicas de los chips son legibles, usa esas etiquetas en el nombre o anotalas en `notes/hardware-notes.md`.
